    Persyaratan peserta

      Satu formulir untuk satu peserta. Pengiriman formulir belum menjamin ketersediaan tempat. Semua pendaftaran berstatus Menunggu konfirmasi.

      Pendaftaran belum dibuka atau sudah ditutup. Silakan hubungi admin Jelajah Terra.

      Isi data peserta di bawah ini. Kolom bertanda * wajib diisi.

      1. Identitas peserta

      Nomor Indonesia, misalnya 081234567890 atau +6281234567890.

      2. Informasi kesehatan

      Informasi ini digunakan untuk persiapan kegiatan. Beri tahu admin jika ada perubahan. Formulir ini tidak memberikan diagnosis atau menentukan kelayakan mengikuti kegiatan secara otomatis.

      3. Kontak darurat

      Gunakan nomor Indonesia: 08…, 628…, atau +628….

      4. Persetujuan

      Data kontak dan kesehatan tidak ditampilkan kepada publik. Hanya admin yang berwenang mengelola data ini untuk administrasi serta persiapan kegiatan.

      Pastikan data sudah benar sebelum mengirim.
